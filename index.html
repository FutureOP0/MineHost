Features

Built Different.

Every feature engineered for a single purpose — running production-grade Minecraft servers from your pocket.

Blazing Fast Performance

A real JVM running natively on your phone, delivering desktop-class tick rates and memory efficiency. Start a server in seconds and maintain a rock-solid 20 TPS.

> server start --software paper --version 1.21
[INFO] Loading server.jar (Paper 1.21.11)
[INFO] Done (4.2s)! Server running on 0.0.0.0:25565
[INFO] TPS: 20.0 | RAM: 312MB / 1024MB

Global Tunneling

Integrated playit.gg tunneling exposes your server to the public internet instantly. Friends connect from anywhere — no port forwarding needed.

Full File Manager

Browse, edit, and manage every file on your server. Edit configs in-app, upload plugins, adjust world settings — all from your phone.

Live Console

Full command-line access to your running server. Execute commands, view logs in real-time, and manage players with zero delay.

Background Resilience

Your server runs as a foreground service with wake locks and WiFi locks. Minimize the app, lock your phone — the server stays up. Built for 24/7 uptime on mobile hardware with zero interruptions.
